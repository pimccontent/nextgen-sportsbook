# Competitor UX Research (patterns only)

Sources reviewed 2026-11-12:
- https://www.sportybet.com/gh/
- https://www.betano.com.gh/

Do **not** copy branding, logos, copy, assets, or exact layouts.

## Observations

### SportyBet Ghana
- Dense fixture table with 1 / X / 2 odds cells and “+N markets”.
- Left “Popular” competitions rail; center feed; right persistent bet slip.
- Booking code load on empty slip.
- Product nav + sports secondary nav.
- Mobile number login/register pattern for Ghana.
- Responsible gaming and licence notes in footer.

### Betano Ghana
- Darker premium shell with left sports/favourites nav.
- Live / Upcoming mode toggle.
- Odds controls expose clear accessible names.
- Slip supports booking code and Open / Settled my-bets tabs.
- Heavy promo density on first viewport (welcome modal, boosts, casino).

## Recommendations for NextGen (original)

1. Keep three-pane desktop shell (leagues · fixtures · slip) without cloning chrome.
2. Prefer cleaner first viewport: brand, mode toggle, fixtures, slip — minimal promo clutter.
3. Strong odds states: selected, suspended, closed, up/down movement.
4. Mobile: bottom nav + slip peek bar + sheet; desktop: sticky right slip.
5. Customer identity: navy/charcoal + restrained lime (not competitor red/orange).
6. Label all odds and balances as mock until live feeds/payments are approved.
