NextGen Sportsbook

Live Server Installation Guide

Single-VPS production install · Path URL layout · Docker + Caddy HTTPS

Updated: 26 November 2026 · Sandbox / mock money until licensing go-live is approved

1. What you need

  • A Linux VPS: Ubuntu 22.04 or 24.04, root SSH access
  • 2 GB RAM minimum (4 GB recommended for first image build)
  • A domain name you control (DNS panel access)
  • An email address for Let’s Encrypt certificates
  • Not for classic shared hosting / cPanel PHP-only
Compliance: This install runs in sandbox / test mode. Do not process real-money bets until licensing, payments, data rights, and responsible-gambling requirements are independently reviewed and approved.

3. Step-by-step installation

  1. Create the VPS
    Provision Ubuntu 22.04/24.04. Note the public IPv4 address. Confirm you can SSH as root (or a user with sudo).
  2. Add DNS records (do this first)
    In your DNS provider, create these A records pointing to the VPS IP:
    HostnameTypeTarget
    YOUR_DOMAINAVPS public IP
    admin.YOUR_DOMAINAVPS public IP
    Optional: www.YOUR_DOMAIN redirects to the apex automatically via Caddy.
    Wait for DNS to propagate (often a few minutes). Certificates fail if DNS is wrong.
  3. (Optional but recommended on 1–2 GB VPS) Add swap 
    sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
  4. SSH into the VPS as root 
    ssh root@YOUR_VPS_IP
  5. Run the guided installer (smoothest) 
    curl -fsSL https://raw.githubusercontent.com/pimccontent/nextgen-sportsbook/main/scripts/install-vps.sh | bash -s -- --wizard --install-docker
    The wizard will ask for:
    • Apex domain (example: bet.example.com)
    • Let’s Encrypt email
    • URL layout — choose path (recommended)
    • Whether to use prebuilt images if available
    It then checks DNS, installs Docker if needed, opens firewall ports 22 / 80 / 443, and starts the stack.
  6. Or use the non-interactive one-liner 
    curl -fsSL https://raw.githubusercontent.com/pimccontent/nextgen-sportsbook/main/scripts/install-vps.sh | bash -s -- --domain=YOUR_DOMAIN --email=YOU@EMAIL.com --install-docker
    Replace YOUR_DOMAIN and YOU@EMAIL.com with real values.
  7. Wait for the first build
    The first run can take several minutes while Docker images build. When finished you should see Customer / Agent / Admin / API URLs printed in the terminal.
  8. Verify HTTPS and health
    • Open https://YOUR_DOMAIN/ — customer app
    • Open https://YOUR_DOMAIN/agent — agent portal
    • Open https://admin.YOUR_DOMAIN — admin portal
    • Open https://YOUR_DOMAIN/api/v1/health — API should return healthy JSON
  9. Sign in to Admin
    Demo Super Admin (seeded when the database has zero users):
    Emailadmin@nextgen.local
    PasswordPassword1!
    Change this password immediately after first login.
  10. Confirm domain layout in Admin
    Go to Settings → Domain & deploy to see portal URLs, required DNS hosts, and the update command.

4. What the installer does

  1. Installs packages (curl, git, ufw, …)
  2. Installs Docker Engine + Compose v2
  3. Clones the repo into ~/nextgen-sportsbook
  4. Opens firewall ports 22 / 80 / 443
  5. Checks DNS for apex + admin.
  6. Writes .env.vps with HTTPS URLs and CORS
  7. Starts Postgres, Redis, API, Customer, Admin, Agent, and Caddy
  8. Caddy obtains Let’s Encrypt certificates for the two hostnames

5. Day-2 operations

Update the stack

cd ~/nextgen-sportsbook
bash scripts/update-vps.sh
# optional:
bash scripts/update-vps.sh --pull-git
bash scripts/update-vps.sh --build

Useful commands

bash scripts/check-dns.sh --domain=YOUR_DOMAIN
docker compose -f infrastructure/docker-compose.vps.yml --env-file .env.vps --profile https ps
docker compose -f infrastructure/docker-compose.vps.yml --env-file .env.vps logs -f api

If you change public URLs / Next env

docker compose -f infrastructure/docker-compose.vps.yml --env-file .env.vps --profile https up -d --build customer admin agent

6. Alternatives

IP-only (no domain / no HTTPS) — testing only

curl -fsSL https://raw.githubusercontent.com/pimccontent/nextgen-sportsbook/main/scripts/install-vps.sh | bash -s -- --install-docker --host=YOUR_VPS_IP

Serves customer :3000, admin :3001, agent :3002, API :8081 over HTTP.

Legacy four-host layout

Only if you need separate agent. and api. subdomains:

bash scripts/install-vps.sh --domain=YOUR_DOMAIN --email=YOU@EMAIL.com --layout=hosts --install-docker

Also requires A records for agent.YOUR_DOMAIN and api.YOUR_DOMAIN.
